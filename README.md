# Paperline downloads

Signed Android releases, update metadata, checksums and release notes for Paperline.
This repository contains no application source or signing keys.

[Download the latest release](https://github.com/Benighter/Paperline-Releases/releases/latest)

[Public app listing](https://benighters-personal-projects.vercel.app/#archive)

[Update feed](https://benighters-personal-projects.vercel.app/releases/paperline/latest.json)

Paperline works without an account or ads. Documents and OCR stay on the device;
manual ZIP backup and restore use Android Files. Document AI is disconnected.
English and 15 partial translations are included, with English fallback.

Android 8 or newer. The first public APK supports ARM64 and x86_64.
Android asks for confirmation before installing an update.
